# 掌阅水波纹助手

为掌阅 E-Ink 阅读设备尝试接入系统 PAGE_H 水波纹。

版本 **0.3.1**，实验性调试版。实测设备为 Ocean 5 Pro / Android 14，不保证其他固件或设备兼容。

## 0.3.1 触屏修复

原方案每次点按等待 App 授权，实测 12–54 毫秒的快速点按会早于 40–176 毫秒的授权完成，导致漏触发。现在由 App 在正文稳定时同步排除控件的区域，桥接直接处理触屏释放；不截获、不延迟、不替换原输入。

区域授权 900 毫秒过期，正常每 250 毫秒尝试续期；焦点改变、休眠、区域命中或失去授权时跳过。自绘弹窗与动态控件仍有缓存时差风险，不保证全部识别。新增 22 项区域、焦点、过期和短点按逻辑测试；连同原有测试共 117 项（其中 12 项为源码检查）。

实机已收到预授权模式的连续触屏调用，物理水波纹完整性仍需用户确认。

## 0.3.0 修复

- 删除所有阅读器的“交换前后按键”“按键托管”、PageUp 转换及多看横滑实验入口；历史设置不再读取。
- 原实体键的按下、抬起及连按始终透传。助手只准备动效，不吞键、不排队、不重新注入按键或触摸。
- 按键动效调用失败不再全局暂停触屏；未确认内容变化时也不自动重试。
- 无障碍重连时关闭旧触屏客户端，避免多个连接竞争。
- 定期检测桥接；桥接退出时显示触屏不可用，恢复后自动重连。普通 APK 不能自行取得 Root 权限或拉起 Root 桥接。
- 多看按键水波纹适配暂停，不作为已解决功能推荐。

保留每应用阅读界面绑定、动效方向反转、三档速度、旋转方向映射、按下/松开原按键时准备动效及原触屏观察。

## API 来源和许可

## 构建

Windows PowerShell + 原生 Java / Android UI，无第三方 UI 框架。自行准备：

- JDK，开发环境为 JDK 21，编译目标 Java 8。
- Android API 34 的 `android.jar`：放入 `tools/platform/android-34/android.jar`。
- Android Build Tools：放入 `tools/build/android-14/`，包含 aapt2、zipalign、lib/apksigner.jar。
- 兼容的 D8/R8 jar：需含 `com.android.tools.r8.D8`，开发环境使用 D8 8.13.17。

```powershell
./build.ps1 -Jdk 'C:\path\to\jdk' -D8Classpath 'C:\path\to\r8.jar'
adb install -r ./dist/pageh-helper-0.3.1.apk
./start-bridge.ps1 -Adb 'C:\path\to\adb.exe'
```

可通过 `JAVA_HOME` 和 `R8_JAR` 环境变量提供构建工具路径；桥接脚本默认使用 PATH 中的 `adb`，也可传 `-Adb` 指定路径。

构建会签署调试 APK、验证签名，运行 105 项方向/窗口/输入分类/触屏授权测试和 12 项被动输入源码检查，共 117 项。源码检查不是运行时或面板测试。调试密钥在 `build/debug.keystore`，不要公开或用于正式发行；不同签名的 APK 不能直接覆盖安装。

## 使用

1. 在已有 ADB Root 的设备启动桥接；脚本不会获取 Root，不配置开机启动。
2. 开启助手无障碍服务和总开关；打开正文，再返回助手绑定该阅读界面。
3. 阅读器自行开启原按键翻页，并将软件翻页动画设为“无”。
4. 需要触屏动画时，开启该应用的“原触摸翻页动效”。仅启用无障碍不足以提供原触屏观察，需桥接运行。
5. 重启设备或桥接退出后，在电脑重新启动桥接。更新桥接代码前先执行 `./stop-bridge.ps1`，再启动；两个脚本均可用 `-Adb` 指定工具。

0.3.1 使用 v4 本地 socket；必须同时更新 APK 和桥接，不要混用旧桥接。已有阅读器绑定、速度、触屏开关保留；已移除的旧设置只会被忽略。

## 验证和限制

内置跨进程测试已验证原按键单次翻页、按键后触屏仍触发动效命令、桥接断开后原键继续翻页，以及桥接恢复后触屏重连。番茄已记录到原生按键与原触屏的动效调用和内容变化。**这些日志不能证明面板动画完整，仍须用户目视验收。**

原触屏依赖当前触屏型号和坐标范围；同 Activity 自绘弹窗、评论控件可能识别不准。不要绑定书架、菜单或系统界面。没有面板完成回调，不能承诺每页零遗漏。

目录：`app/` 源码与矢量图标，`tests/` 测试，`build.ps1` 构建，`start-bridge.*` / `stop-bridge.*` 桥接管理。构建产物、SDK、厂商二进制和设备数据均被排除。
